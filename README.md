# QR Code Generator

Gerador de QR Code desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Geração instantânea de QR Codes
- Interface simples
- Integração com API pública de QR Code

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como usar

1. Digite um texto ou URL.
2. Clique em "Gerar QR Code".
3. O QR Code será exibido na tela.
